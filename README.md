# כיס חכם — ארגז כלים אופליין לאנדרואיד

אפליקציית Android בעברית עם 96 כלים מקומיים. ללא חשבון, ללא שרת וללא הרשאת INTERNET.

## כלים כלולים
- מתמטיקה: מחשבון ביטויים, אחוזים, הנחות, מס, טיפ, חלוקה, ממוצע, חציון, סטיית תקן, כלל שלוש, שברים, בסיסי מספרים, עצרת, מספרים ראשוניים, GCD/LCM ועיגול.
- המרות: אורך, משקל, טמפרטורה, שטח, נפח, מהירות, נתונים, זמן, לחץ, אנרגיה, הספק, מידות מטבח, DP/PX וצריכת דלק.
- טקסט: ספירה, שינוי אותיות, היפוך, ניקוי, מיון שורות, הסרת כפילויות, השוואה, JSON, Base64, URL, Slug, תדירות מילים, בינארי, מורס, ROT13 וקידוד HTML.
- אבטחה ויצירה: SHA-256, מחולל סיסמאות, בדיקת חוזק סיסמה, UUID, מספרים אקראיים, קוביות, מטבע וצירופי מילים.
- זמן ותכנון: הפרש תאריכים, הוספת ימים, יום בשבוע, שנה מעוברת, חותמת זמן, שעון עצר, טיימר, פומודורו, מטרונום, פתקים, רשימת משימות, מחשבון גיל ושעות עבודה.
- מכשיר ויצירה: QR, ברקוד, מידע מכשיר, סוללה, אחסון, חיישנים, מצפן, פלס, RGB/HEX ויחס תמונה.

## שיפורים בגרסה הנוכחית
- ממשק בית מעודכן עם גישה מהירה לכלים נפוצים, קטגוריות וחיפוש.
- תיקון המרת DP לפיקסלים, שדות קלט לכלל שלוש, בדיקת מספרים רומיים וטיפול בטווחים אקראיים.
- מטרונום עם בחירת BPM ורשימת משימות עם סימון, מחיקה ושמירה מקומית.
- נוספו 12 כלים: עצרת, מספר ראשוני, GCD/LCM, עיגול, שינוי באחוזים, מחשבון גיל, שעות עבודה, צריכת דלק, HEX ל-RGB, ROT13, קידוד HTML ובדיקת דוא״ל.

## פרטיות ואופליין
- אין הרשאת `INTERNET` במניפסט.
- אין SDK של אנליטיקה, פרסומות או חשבונות.
- מועדפים והפתקים נשמרים ב-SharedPreferences מקומי.
- חיישנים נקראים דרך SensorManager בלבד.
- QR וברקוד מיוצרים על המכשיר בעזרת ZXing.

## בניית APK
GitHub Actions בונה APK מסוג Debug בכל Push ל-main וגם בהפעלה ידנית:
1. פתח Actions.
2. בחר Build Smart Pocket APK.
3. הורד את `SmartPocket-offline-debug-apk`.
4. חלץ את ZIP והתקן את `app-debug.apk`.

### בנייה מקומית
דרושים JDK 17 ו-Gradle 8.9:
```bash
gradle --no-daemon clean assembleDebug
```
פלט: `app/build/outputs/apk/debug/app-debug.apk`

## מגבלות
חלק מהכלים מבוססים על קלט משתמש וחלקם קוראים מידע בסיסי מהטלפון. מצפן ופלס תלויים בחיישנים הקיימים במכשיר. נתוני המרה הם קבועים מתמטיים; אין שערי מטבע או נתוני רשת שמתעדכנים בזמן אמת.
