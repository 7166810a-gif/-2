# MEGA POCKET X — כיס חכם אולטימטיבי

אפליקציית Android בעברית, עם ממשק RTL, שנבנית כמרכז כלים אופליין אחד.

## החלטות מוצר
- יעד: Android 13 (API 33), עם minSdk 26.
- שפה: Kotlin + Jetpack Compose.
- התקנה: APK יחיד הכולל את כל המודולים.
- מצב רשת: ללא הרשאת INTERNET; אין חשבון, שרת, פרסומות או אנליטיקה.
- אחסון: בחירת קבצים ותיקיות דרך Storage Access Framework בלבד.
- AI: בחירת קובץ מודל מקומי דרך בורר Android; מנוע ההסקה יתחבר בפיתוח נפרד.
- מדיניות נתונים: הגדרות והרשאות בחירה נשמרות במכשיר.

## מצב הפרויקט בשלב 1
- נשמרו 96 הכלים הקיימים של כיס חכם.
- נוסף מסך בית MEGA POCKET X עם 12 מחלקות.
- נוספו מסכי יסוד ל-AI מקומי ולאחסון SD/USB.
- נוספה שכבת קטלוג מודולים ומחלקת גישה מקומית ל-SAF.
- נוספה תשתית GitHub Actions לבניית APK ולהעלאתו כ-artifact.

חשוב: 96 הכלים הקיימים הם הכלים הפעילים כעת. 240 תכונות הן יעד התכנון הכולל; יתר המחלקות מסומנות בממשק כתשתית או בתכנון עד להשלמת המימוש שלהן.

מחלקות features נוספות יתווספו בהדרגה לפי המודולים: קבצים, מדיה, תמונות, שמע, מסמכים, מכשיר, הנדסה, כספת, AI מקומי, פיתוח ויצירה.

## אחסון SD ו-USB
המשתמש בוחר תיקייה דרך Android. האפליקציה שומרת הרשאת URI מתמשכת כשהספק מאפשר זאת, ואינה מבקשת הרשאת אחסון גורפת. התוכן נשאר במקום המקורי ואינו מועתק אוטומטית.

## AI מקומי
שלב 1 מאפשר בחירת קובץ מודל ושמירת הרשאת קריאה. עדיין לא משולב runtime להרצת מודלים, ולכן בחירת הקובץ אינה מציגה צ'אט פעיל. מנוע מקומי ותמיכה בפורמטים ייבנו וייבדקו בשלב ייעודי.

## בניית APK דרך GitHub Actions
1. היכנס ללשונית Actions במאגר.
2. בחר Build MEGA POCKET X APK.
3. לחץ Run workflow (או המתן לבנייה אוטומטית לאחר Push).
4. לאחר שהריצה מסתיימת בהצלחה, פתח את הריצה והורד את artifact בשם MEGA-POCKET-X-debug-apk.
5. חלץ את ה-ZIP והתקן את app-debug.apk.

ה-APK בשלב זה הוא APK Debug חתום במפתח debug של Android ומתאים להתקנת בדיקה. APK Release עם מפתח פרטי יוגדר בשלב הפצה נפרד; אין לשמור מפתח חתימה פרטי במאגר ציבורי.

## בנייה מקומית
דרושים JDK 17, Android SDK ו-Gradle 8.9:
```bash
gradle --no-daemon clean assembleDebug
```
פלט: app/build/outputs/apk/debug/app-debug.apk

## אופליין בפועל
האפליקציה אינה כוללת הרשאת INTERNET. תהליך הבנייה ב-GitHub Actions זקוק לחיבור רשת כדי להוריד Gradle ותלויות, אך האפליקציה המותקנת אינה תלויה בשירות רשת.
