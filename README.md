# כיס חכם — ארגז כלים אופליין לאנדרואיד

אפליקציית Android בעברית עם כ-75 כלים מקומיים. ללא חשבון, ללא שרת וללא הרשאת INTERNET.

## כלים כלולים
- מתמטיקה: מחשבון ביטויים, אחוזים, הנחות, מס, טיפ, חלוקה, ממוצע, חציון, סטיית תקן, כלל שלוש, שברים ובסיסי מספרים.
- המרות: אורך, משקל, טמפרטורה, שטח, נפח, מהירות, נתונים, זמן, לחץ, אנרגיה, הספק, מידות מטבח ו-DP/PX.
- טקסט: ספירה, שינוי אותיות, היפוך, ניקוי, מיון שורות, הסרת כפילויות, השוואה, JSON, Base64, URL, Slug, תדירות מילים, בינארי ומורס.
- אבטחה ויצירה: SHA-256, מחולל סיסמאות, בדיקת חוזק סיסמה, UUID, מספרים אקראיים, קוביות, מטבע וצירופי מילים.
- זמן ותכנון: הפרש תאריכים, הוספת ימים, יום בשבוע, שנה מעוברת, חותמת זמן, שעון עצר, טיימר, פומודורו, פתקים, רשימות ומונה.
- מכשיר ויצירה: QR, ברקוד, מידע מכשיר, סוללה, אחסון, חיישנים, מצפן, פלס, צבע ויחס תמונה.

## פרטיות ואופליין
- אין הרשאת `INTERNET` במניפסט.
- אין SDK של אנליטיקה, פרסומות או חשבונות.
- מועדפים והפתקים נשמרים ב-SharedPreferences מקומי.
- חיישנים נקראים דרך SensorManager בלבד.
- QR וברקוד מיוצרים על המכשיר בעזרת ZXing.

## בניית APK
GitHub Actions בונה APK מסוג Debug בכל Push ל-main וגם בהפעלה ידנית:
1. פתח Actions.
2. בחר Build Smart Pocket APK.
3. הורד את `SmartPocket-offline-debug-apk`.
4. חלץ את ZIP והתקן את `app-debug.apk`.

### בנייה מקומית
דרושים JDK 17 ו-Gradle 8.9:
```bash
gradle --no-daemon clean assembleDebug
```
פלט: `app/build/outputs/apk/debug/app-debug.apk`

## מגבלות
חלק מהכלים מבוססים על קלט משתמש וחלקם קוראים מידע בסיסי מהטלפון. מצפן ופלס תלויים בחיישנים הקיימים במכשיר. נתוני המרה הם קבועים מתמטיים; אין שערי מטבע או נתוני רשת שמתעדכנים בזמן אמת.
